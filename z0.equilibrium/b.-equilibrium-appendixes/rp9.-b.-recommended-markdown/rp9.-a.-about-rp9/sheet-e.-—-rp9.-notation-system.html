The goal is not to explain each symbol individually.

Nor is the goal to analyze the relational functions between the symbols.

Detailed symbol definitions and relational analyses are covered in later documents.

PURPOSE

This document constitutes the second summary of the formula.

The purpose is to define the symbols individually.

This document deals with:

  • Meaning of individual symbols

  • Basic functions

  • Conceptual definition

This document does not deal with:

  • Relational analyses

  • Sequential logic

  • The mutual functions of transformations

Each symbol is therefore described as an independent meaning carrier.

Relational analyses are dealt with in later documents.

CONCLUSION

Each symbol in the formula represents a single function or meaning bearer.

No symbol exists in isolation in the complete formula, but before the relationships between them are analyzed, each symbol must first be defined individually.

This document therefore constitutes the basic vocabulary of the symbol system.

By defining each symbol separately, a common frame of reference is created for the relational analyses that follow in later documents.

First, the symbols are defined. Then, the relationships between them can be analyzed.

RELATIONAL FUNCTIONS

Purpose

This document constitutes the third summary of the formula.

The previous summaries dealt with:

  • First summary — each row as a whole.

  • Second summary — each symbol individually.

The third summary describes the relational functions that arise when several symbols are combined.

The focus is therefore not on individual symbols but on their interaction.

FUNCTION 1

Relational function

This combination describes the transition from scale-independent potential to observable structure.

  • The potential exists first.

  • Alpha–Omega serves as the first symbolic description of this potential.

  • The relational equivalence shows that both expressions describe the same underlying state.

  • The final line expresses the first observable manifestation of the potential.

FUNCTION 2

Relational function

This combination defines H-D-R as a scale-independent transformation principle.

  • The transformation operator can be applied in both directions.

  • The result is not a specific structure.

  • The result is a general rule for how relations are transformed.

FUNCTION 3

Relational function

This sequence describes how the first geometric relation arises from the transformation principle.

  • The transformation is applied.

  • A geometric relation arises.

  • An observable proportion is established.

The result is the first observable proportion:

which can then be expressed as a measurable relationship.

FUNCTION 4

Relational Function

This sequence describes how a relationship can be maintained across different scales while maintaining a permanent difference.

Two states exist simultaneously:

  • Balance

  • Difference

FUNCTION 5

Relational function

This sequence describes how repeated transformations lead to a stabilized relational state.

  • The structure reaches equilibrium.

  • The difference is not eliminated.

  • The residual serves as verification that the relation still exists.

FUNCTION 6

Relational function

This sequence describes the numerical evolution of the potential.

  • Each step builds on the previous relation.

  • Each step is a transformation.

  • No new relation is created.

Each term is a new expression of the same underlying structure.

FUNCTION 7

⬡🧊
Relational function

This sequence describes the same development expressed geometrically.

  • Each shape represents a new observation mode.

  • Each shape represents the same underlying structure.

  • Geometry acts as an alternative language for the same relation.

CONCLUSION

The first summation describes:

What each row represents.

The second summation describes:

What each symbol means.

The third summary describes:

What happens when the symbols are combined.

It is only at this level that the formula begins to function as a coherent relational notation system.
