Purpose

This group contains the basic relational axioms used throughout RP9.

The documents do not define:

  • specific sequences

  • verification chains

  • code implementations

  • final declarations

Their function is instead to establish the minimal principles that enable the relational derivation that the rest of RP9 builds on.

Function

The group describes the relationship between:

Potential
↓
Relation
↓
Structure
↓
Projection

and how latent form can become explicit without adding new information.

The focus is on:

  • level separation

  • relational continuity

  • operational explicitation

  • structural invariance

Content

A. Potential → Relation → Structure → Projection

Defines the minimal relational chain.

Establishes the difference between:

  • potential

  • relation

  • structure

  • projection

B. Form before manifestation

Defines the difference between:

  • latent form

  • explicit manifestation

and establishes the principle:

Form before manifestation

C. Pre-Formation as operatoric explicitation

Defines H–D–R as:

explicitization operator

and describes how latent structure becomes observable.

D. Verified operatoric formulation

Verifies that the relational chain:

Potential
↓
Relation
↓
Structure
↓
Projection

can be derived without:

  • free parameters

  • external information injection

  • arbitrary operations

SHEET — (A)

POTENTIAL → RELATION → STRUCTURE → PROJECTION

Note

A1 — Classification

A1 — Explanatory support material

  • This document follows the RP9 A1 standard.
    • This document follows the RP9 A1 standard and acts as a human interface to the formal documentation.
      • A1 does not introduce any new axioms, relations or verifications, but acts as a human interface between the formal presentation and the technical verification.
  • APPENDIXES only explain and visualize already verified information.

POSITION

This document defines the minimal relational chain used throughout RP9.

The chain describes the operational order by which:

Potential
↓
Relation
↓
Structure
↓
Projection

can be established.

The document serves as a base sheet for relational level separation.

BASIC PRINCIPLE

RP9 is based on the following order:

Relation before Structure

Structure before Projection

This means that:

no projection can be used
as a legitimation
for the structure
that enabled the projection

Projection can be observed.

Structure must be derived.

AXIOM A1 — POTENTIAL

Definition

Potential is defined as:

capacity without differentiation

Potential contains:

  • no relation

  • no direction

  • no structure

  • no internal distinction

Only the possibility of differentiation exists.

Formal

Properties

• No relation

• No structure

• No direction

• Only capacity

AXIOM A2 — RELATION

Conditions

Relation requires at least two distinct positions.

Operation

D : P → (x₁,x₂)

R : (x₁,x₂) → relation

Formal

Properties

• First differentiation

• First direction

• First connection

• First relational dependence

AXIOM A3 — STRUCTURE

Conditions

Structure requires at least three relational positions.

Justification

2 → relation possible

3 → structure possible

Two positions enable connection.

Three positions enable relational organization.

Formal

Properties

• Relational field

• Internal organization

• Relational coherence

• Structural stability

AXIOM A4 — PROJECTION

Conditions

Structure exists.

Operation

Definition

Projection is defined as:

representation of established structure

Properties

• Structural compression

• Representation

• Information reduction

• Observable manifestation

H–D–R

Operators

H
=
Separation

D
=
Differentiation / Expansion

R
=
Relation / Connection

These operators enable the transition between levels.

AXIOM A5 — GENERATIVE CHAIN

The following dependencies apply:

Potential cannot be projected directly.

Relation cannot exist without differentiation.

Structure cannot exist without relation.

Projection cannot exist without structure.

Formal

MINIMAL INVARIANCE

|P| = 1
↓
Potential

|R| ≥ 2
↓
Relation possible

|S| ≥ 3
↓
Structure possible

Π(S)
↓
Representation

CONDENSED FORM

1
↓
2
↓
3
↓
n
↓
1

GEOMETRIC REALIZATION

Potential
↓
Sphere

Relation
↓
Two spheres

Structure
↓
Vesica Piscis

Projection
↓
Planar representation

SYSTEMIC CONSEQUENCE

The following dependencies apply throughout RP9:

Relation enables structure.

Structure enables projection.

Projection represents structure.

Structure cannot be reduced to projection.

LEVEL SEPARATION

It is therefore necessary to distinguish between:

Primary level

Potential
↓
Relation
↓
Structure

and:

Secondary level

Projection
↓
Representation
↓
Observation

The primary level establishes.

The secondary level represents.

END POSITION

The minimal relational chain can be summarized as:

Potential
↓
Relation
↓
Structure
↓
Projection

and:

Relation before Structure

Structure before Projection

This order constitutes the basic level separation used throughout the RP9 system.

SHEET — (B).md

BLAD (B) — FORM FÖRE MANIFESTATION

SHEET — (B)

FORM BEFORE MANIFESTATION

Note

A1 — Classification

A1 — Explanatory support material

  • This document follows the RP9 A1 standard.
    • This document follows the RP9 A1 standard and acts as a human interface to the formal documentation.
      • A1 does not introduce any new axioms, relations or verifications, but acts as a human interface between the formal presentation and the technical verification.
  • APPENDIXES only explain and visualize already verified information.

POSITION

This document defines the relationship between:

latent form

and:

explicit manifestation

within RP9.

The function of the document is to establish the principle that:

form can exist
without being manifested

and that manifestation requires operation.

BASIC PRINCIPLE

RP9 distinguishes between:

Form

and:

Manifestation

Form is defined as:

relational possibility

Manifestation is defined as:

explicit observable structure

These are not the same state.

THEOREM B1

Form does not have to be visible
to exist.

Observability is not a requirement for form.

Observability is a requirement for manifestation.

LATENT FORM

Latent form is defined as:

a structural possibility
that has not yet been made explicit

Latent form is therefore:

  • non-observable
  • non-manifest
  • relationally possible

but not yet explicit.

THEOREM B2

Lack of manifestation
is not lack of form.

This means that:

non-visible
≠
non-existent

at the relational level.

THEOREM B3

Operation precedes manifestation.

Manifestation cannot therefore occur without an operational transition.

FORM AND STRUCTURE

When latent form is made explicit, the following occurs:

relation
↓
structure
↓
observation

What is observed is therefore:

manifestation

not the latent form itself.

CRITICAL DISTINCTION

RP9 distinguishes between:

creation

and:

explicitization

Creation

new information is introduced

Explicitization

existing relational possibility is made observable

THEOREM B4

Manifestation does not mean that a new structure has been created.

Manifestation means that:

structure has become observable.

RELATION TO SHEET A

SHEET A establishes:

Potential
↓
Relation
↓
Structure
↓
Projection

SHEET B establishes:

Form
↓
Operation
↓
Manifestation
↓
Observation

They describe the same process from two different perspectives.

SYSTEMIC CONSEQUENCE

The following order applies:

Form
↓
Operation
↓
Manifestation
↓
Observation
↓
Form

END POSITION

Form is defined as:

latent structural possibility

Manifestation is defined as:

explicit observable structure

Therefore:

Form precedes manifestation.

and:

Operation enables manifestation.

Manifestation does not create form.

Manifestation makes form observable.

SHEET — (C)

PRE-FORMATION AS OPERATORY EXPLICITATION (FORMALLY LOCKED)

Note

A1 — Classification

A1 — Explanatory support material

  • This document follows the RP9 A1 standard.
    • This document follows the RP9 A1 standard and acts as a human interface to the formal documentation.
      • A1 does not introduce any new axioms, relations or verifications, but acts as a human interface between the formal presentation and the technical verification.
  • APPENDIXES only explain and visualize already verified information.

POSITION

This document defines H–D–R as an operator for explicitation.

The function of the document is to describe how latent form transitions to explicit structure.

This document does not deal with:

  • creation

  • supplied information

  • external generation

but:

operational explicitation

of already existing relational possibility.

RELATION TO SHEETS A AND B

SHEET A establishes:

Potential
↓
Relation
↓
Structure
↓
Projection

SHEET B establishes:

Form
↓
Operation
↓
Manifestation

SHEET C describes:

which operation
that enables the transition

H–D–R

H–D–R is defined as:

H
=
Separation

D
=
Differentiation / Expansion

R
=
Relation

The operator functions as a transition between latent and explicit states.

THEOREM C1

H–D–R does not create structure.

H–D–R makes structure explicit.

POTENTIAL

The initial state is defined as:

P0

with properties:

no relation

no direction

no structure

no explicit difference

Potential contains possibility.

Not manifestation.

FIRST OPERATION

P0
↓
H–D–R
↓
Relation

The result is not a finished structure.

The result is:

first relation

THEOREM C2

Relation arises through operation.

Relation precedes structure.

FIRST EXPLICIT FORM

When relation is established, there arises:

sphere ∩ sphere
↓
circle

The first observable form.

THEOREM C3

Form arises from relation.

Not from isolated states.

SECOND OPERATION

The established relation then undergoes a new operation:

circle
↓
H–D–R
↓
Vesica Piscis

DIFFERENCE

Through Vesica Piscis arises:

The difference becomes explicit.

THEOREM C4

Difference arises in structure.

Not before relation.

STRUCTURAL CONSEQUENCE

When the difference becomes explicit, it enables:

lines
axes

orientation

direction

These are consequences.

Not origins.

THEOREM C5

Direction is a consequence of difference.

Not a primary structure.

INFORMATION

RP9 distinguishes between:

latent information

and:

explicit information

Latent

Information exists as a possibility.

Explicit

Information exists as an observable structure.

THEOREM C6

H–D–R does not generate information.

H–D–R makes information observable.

INVARIANCE

The following conditions apply:

No external information is added.

No free parameter is introduced.

All relations are derived from the previous level.

OPERATORY DEFINITION

H–D–R functions as:

latent
↓
relation
↓
explicit

and not as:

nothing
↓
creation
↓
structure

CORE CHAIN

P0
↓
H–D–R
↓
Relation
↓
Circle
↓
H–D–R
↓
Vesica Piscis
↓
Δ
↓
Lines
↓
Axes
↓
Direction

END POSITION

Pre-formation is defined as:

latent form
that requires operation
to become explicit

H–D–R therefore functions as:

explicitizing operator

and not as:

creation operator

The central principle of the document can summarized as:

H–D–R does not create structure.

H–D–R makes structure observable.

SHEET — (D)

VERIFIED OPERATIVE FORMULATION

Note

A1 — Classification

A1 — Explanatory support material

  • This document follows the RP9 A1 standard.
    • This document follows the RP9 A1 standard and acts as a human interface to the formal documentation.
      • A1 does not introduce any new axioms, relations or verifications, but acts as a human interface between the formal presentation and the technical verification.
  • APPENDIXES only explain and visualize already verified information.

POSITION

This document verifies the relational chain established by:

SHEET A
Potential → Relation → Structure → Projection

SHEET B
Form before manifestation

SHEET C
Pre-Formation as operator explicitation

The function of the document is to check whether the defined chain satisfies its own invariance requirements.

PURPOSE

The purpose is to determine whether:

latent form
↓
operation
↓
explicit structure

can be derived without:

  • external information being added
  • free parameters being introduced
  • relational continuity being broken

VERIFICATION OBJECT

The following statements are examined:

1.
Relation precedes structure

2.
Structure precedes projection

3.
H–D–R makes structure explicit

4.
Difference arises in structure

5.
Direction is consequence
not origin

INVARIANCE REQUIREMENTS

For the model to be internally consistent, the following are required:

No external information

No free parameter

No arbitrary structure

No broken derivation

All steps must be derivable from the previous step.

VERIFICATION CHAIN

The verified chain is defined as:

P0
↓
H–D–R
↓
Relation
↓
Circle
↓
H–D–R
↓
Vesica Piscis
↓
Δ
↓
Lines
↓
Axes
↓
Direction

Each level should be derivable from the previous level.

THEOREM D1

No structure is assumed in advance.

The structure arises sequentially through relational operations.

THEOREM D2

Relation precedes form.

No form is established without a preceding relation.

THEOREM D3

Form precedes difference.

Difference becomes explicit only when structure has been established.

THEOREM D4

Difference precedes direction.

Lines, axes and orientation arise as consequences of explicit difference.

OPERATOR VERIFICATION

H–D–R is analyzed in two different modes.

PHASE A — BEFORE STRUCTURE

H
=
Separation

D
=
Differentiation

R
=
Relate

No rotation is possible.

No direction exists.

No structure exists.

PHASE B — IN STRUCTURE

H
=
Separation

D
=
Differentiation

R
=
Orientation

Now there are:

  • relation
  • difference
  • lines
  • axes
  • direction

The operator therefore gets a new reading.

THEOREM D5

The operator does not change nature.

The operator changes reading
depending on the level.

INFORMATION CHECK

The following is checked:

Is new information added?

Answer:

No.

Justification

All relations are derived from:

previous relation

and not from:

external input

PROJECTION CHECK

The following is checked:

Is information created
or is information represented?

Answer:

Information is represented.

JSON, Markdown, visualizations and datasheets act as:

projections

not as creation mechanisms.

THESIS D6

Projection does not create structure.

Projection represents structure.

FINAL VERIFICATION

The following chain is verified:

Potential
↓
Relation
↓
Form
↓
Difference
↓
Structure
↓
Direction
↓
Projection

without:

external information

free parameters

arbitrary steps

CONCLUSION

The verified formulation supports the following position:

Latent structure
can be made explicit
without creating new structure.

and:

H–D–R functions as
explicitization operator.

not as:

creation operator.

ENDPOSITION

The basic relational axioms can be summarized as:

Potential
↓
Relation
↓
Structure
↓
Projection

and:

Form
↓
Operation
↓
Manifestation

where:

H–D–R

functions as the operator that enables the transition between latent and explicit states.

This document verifies that this chain remains internally consistent throughout the relational derivation.
