3.1 Relational method

The meta-mathematical presentation starts from the same relational model as previously declared.

No new model is introduced in this section.

No new relation is established.

No previous verification is replaced.

The purpose is to express the previously established relational structure through a formal representation layer.

Relation before representation

RP9's method assumes that relation precedes representation.

This means that a symbol, a number, a formula or a notation is not treated as the primary structure.

They are treated as representations of previously established relations.

The relational structure is therefore primary.

The representation is secondary.

Structure before projection

RP9's method further assumes that structure precedes projection.

A projection cannot be treated as original if it is based on a structure that must already be established for the projection to be defined.

The meta-mathematical presentation therefore starts from the previously established order:

Potential

↓

Differentiation

↓

Relation

↓

Structure

↓

Projection

↓

Representation

This order is the basis for how notation and formula structure are used in the subsequent presentation.

Function before notation

RP9 distinguishes between function and notation.

Notation is used to communicate a relational function.

Notation does not create the function.

It denotes it.

Therefore, each symbol in the meta-mathematical presentation must be able to be traced back to a previously defined relational function.

No notation may be introduced as a stand-alone symbol.

No formula may be treated as primary unless it can first be related to the underlying structure it represents.

Derivation before formalization

The formal presentation follows the relational derivation.

The formalization is therefore placed after:

  • basic definitions,

  • question,

  • declared position,

  • relational application,

  • and verification basis.

This means that the meta-mathematical presentation is not used to create the RP9 model.

It is used to represent the model that has already been established through the presentation and verification chain.

Methodological principle

The underlying structure does not change through how it is represented.

Only the representational form changes.

The structure is invariant.

The form is mobile.

This means that the same relational structure can be expressed through:

  • relational description,

  • code,

  • mathematical notation,

  • and verbal documentation,

without these constituting separate models.

They describe the same previously established structure through different representation layers.

META-FUNCTIONAL PRINCIPLE

RP9 distinguishes between structure and representation.

The relational structure is primary.

All representation layers are secondary functions through which the same structure is expressed, verified and communicated.

The different representation layers therefore have different functions within the methodological hierarchy.

First representation layer

Code

Code constitutes the primary verification layer of the project.

The code represents the relational model through binary operations and reproducible executions.

The function of the code does not change through changes in notation, language or names.

The same code reproduces the same operational structure regardless of how it is later described.

Code is therefore used as the primary verification medium of the project.

  • CLARIFICATION: "Code constitutes the primary reproducible verification of the relational model."

Second representation layer

Mathematical notation

The mathematical notation represents the same previously established structure through the established mathematical symbolic language.

Notation is used for formal representation.

It does not introduce the relational model.

It represents it.

Third representation layer

Verbal documentation

The verbal documentation is used to describe, communicate and document the previously established model.

The language is used for understanding.

It is not used as the project's primary form of verification.

Fourth representation layer

Relational description

The relational description connects all representation layers.

Here, the model is treated as a coherent structure where each established function can be returned to the same relational basis.

This means that no representation form exists in isolation.

Each layer represents the same previously established structure through different forms of expression.

Function

The meta-functional principle establishes the hierarchical order by which RP9 presents and verifies the relational model.

The difference between the representation layers does not lie in the structure described.

The difference lies only in how the same structure is represented.

Function

This section establishes the method that governs the meta-mathematical presentation.

The relational model remains primary.

The meta-mathematical language functions as a secondary representation layer.

The continued notational and formal presentation should therefore be read as a representation of previously established relational structure, not as a stand-alone mathematical model.

3.2 Meta-mathematical language

The relational model has been previously established through definition, derivation, and verification.

This section does not introduce any new content.

The purpose is to express the same previously established relational structure through a meta-mathematical language.

Meta-mathematical representation

RP9 uses mathematical notation as a representation language.

The notation is not used to establish the relational model.

It is used to represent it.

The meta-mathematical language thus functions as a translation between the previously established relational structure and its mathematical representation.

Relation and notation

RP9 distinguishes between relation and notation.

The relation constitutes the primary structure.

The notation functions as a secondary expression for the same previously established relation.

No mathematical symbol is therefore introduced as an independent function.

Each notation must be able to be returned to a previously defined relational function.

Purpose of the meta-mathematical presentation

The meta-mathematical presentation is used to:

  • represent previously established relations,

  • express the model through mathematical notation,

  • create a formal description of the relational structure,

  • and enable an unambiguous transition to the formal derivation.

It does not change the relational model.

It only changes the representation form.

Function

This section establishes the meta-mathematical language through which the previously established relational model is represented.

The language constitutes a formal representation layer.

It does not introduce any new structure.

It represents the same previously established relational model through mathematical notation.

3.3 Notational description

The meta-mathematical presentation uses a number of recurring symbols and notations.

This section establishes their function within the relational model declared by RP9.

The notations do not introduce any new relations.

They function as formal representations of previously established relational functions.

Detailed derivations and relational analyses are presented in subsequent sections.

Basic principle

Each symbol represents a previously defined relational function.

No symbol should be read as a stand-alone definition.

No notation introduces a new structure.

The notation functions as a formal language through which the previously established model is expressed.

Central notations

Δ

Represents relational differentiation.

Δ is used throughout the model to describe the establishment of difference, relation, and structural separation.

Z

Represents the relational reference position used within the meta-mathematical model.

Z is used as part of the formal notation and is understood according to the previously established relational structure.

H–D–R

Denotes the relational operator through which the primary structure is successively established.

H–D–R functions throughout the model as the basic operational principle.

Core4

Represents the primary relational structure established by the H–D–R principle and serves as the basic structural reference of the model.

B5-n6

Represents one of the relational observation positions of the model.

The term is used consistently throughout the further verification and is understood according to the previously established observation structure.

B6-n6

Represents the complementary relational observation position to B5-n6.

Together they constitute the observation structure that is addressed throughout the further verification chain.

META-EQUILIBRIUM

Represents the relational state used to describe the structural equilibrium state of the model.

The term is understood according to the relational model that was previously established and is used consistently throughout the further meta-mathematical presentation.

Other Notations

All other symbols and notations used throughout the formal presentation are defined according to the same methodological principle.

Each notation represents a previously established relational function.

No notation is introduced as an independent model.

Function

This section establishes the notation used throughout the further meta-mathematical presentation.

The purpose is to create an unambiguous symbolic language before the formal formula structure and meta-mathematical derivation are presented.
