1. H–D–R

1.1 Operation

The relational structure is reproduced through the H–D–R operator.

H–D–R consists of three sequential operations:

  • Halving

  • Doubling

  • Relation

No new structure is introduced.

Each iteration reproduces the same relational proportion through a new structural layer.

2. Relational reconstruction

2.1 Reference

All reconstruction starts from the relational reference:

R

R serves as the common reference point of the structure.

2.2 Reconstruction

The first complete reconstruction is expressed by:

Rx8

Rx8 does not introduce any new relation.

It reconstructs the already established relational structure.

The relational reconstruction can be observed by:

  • Square

  • Cube

  • 2D → 3D

The relational structure remains invariant.
