    Four complementary layers — One relational framework

Purpose

Primary Calibration constitutes the primary presentation and computational calibration of the RP9 relational framework.

Its purpose is to establish the invariant relational framework, reproduce it computationally, and prepare it for the complete verification performed within the Secondary Verification.

Rather than presenting independent models, Primary Calibration develops one continuous relational framework through successive methodological stages.

The result is the minimum complete presentation required to establish the framework before its extended computational analysis and verification.

Primary Architecture

Primary Calibration is organised into two complementary methodological layers.

A. THE SEQUENCES (S-series)

↓

B. CODE & VALIDATION (K-series)

The S-series establishes the relational framework through conceptual and methodological presentation.

The K-series reproduces the same framework computationally and provides the primary operational validation.

Together these two layers constitute the complete Primary Calibration.

The S-series establishes the conceptual presentation of the RP9 framework through three sequential methodological stages.

S1 — Relational Derivation

Establishes the invariant relational foundation from potential capacity through the first operational geometry.

S2 — Relational Reproduction

Demonstrates how the invariant H–D–R operator progressively reproduces the complete structural framework while preserving relational continuity.

Within the Primary Calibration, S2 is intentionally presented as a condensed reference edition.

The complete structural derivation is provided within the corresponding section of B. RP9. SECONDARY VERIFICATION.

S3 — Relational Observation

Establishes the observational methodology through which the completed relational framework is examined while preserving structural invariance.

The sequence concludes with the establishment of META-EQUILIBRIUM as the primary observational reference.

B. CODE & VALIDATION (K-series)

The K-series reproduces the framework established by the presentation sequences through computational implementation.

Each code base corresponds directly to the presentation sequence that precedes it.

S2 → K2

S3 → K3

K1 — Code & Validation

Computationally reproduces the relational derivation established within S1.

K2 — Code & Validation

Provides the computational structural reference generated through the invariant H–D–R sequence.

Within the Primary Calibration, K2 is intentionally presented as a condensed reference edition.

The complete computational derivation, metadata, validation, and supporting documentation are provided within B. RP9. SECONDARY VERIFICATION → K2. CODE & VALIDATION.

K3 — Code & Validation

Computationally reproduces the observational methodology established within S3 and performs the primary operational validation of the completed relational framework.

Relationship to Secondary Verification

Primary Calibration establishes the complete relational framework and its primary computational implementation.

The complete structural derivations, extended computational analyses, validation chains, supporting metadata, and supplementary documentation are intentionally organised within:

B. RP9. SECONDARY VERIFICATION

Primary Calibration therefore presents the minimum complete framework required to establish and understand RP9, while Secondary Verification provides its complete computational reproduction and extended verification.

Summary

The Primary Calibration constitutes the first operational layer of the RP9 framework.

Through the combined presentation of the S-series and the computational implementation of the K-series, it establishes the invariant relational framework, reproduces it computationally, and prepares it for the complete structural verification contained within the Secondary Verification.

Together these complementary layers provide the complete methodological foundation upon which the remainder of the RP9 repository is constructed.
